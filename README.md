# سوبر ماركت جي جي

متجر إلكتروني بسيط (ملف `index.html` واحد) يُنشر على GitHub Pages. المنتجات تُجلب من Google Sheet عبر Google Apps Script، والطلبات تُرسل إلى واتساب الفرع المختار وتُسجَّل في جوجل شيت.

## الإعدادات (أعلى السكربت داخل `index.html`)
| الإعداد | الوظيفة |
|---|---|
| `sheetApiUrl` | رابط سكربت المنتجات |
| `BRANCH_WHATSAPP` | رقم واتساب كل فرع (الطلب يصل على رقم الفرع المختار) |
| `ORDERS_API_URL` | رابط سكربت تسجيل الطلبات في جوجل شيت |

## ربط الطلبات بجوجل شيت (مرة واحدة)
1. أنشئ ملف Google Sheet جديد باسم مثل "طلبات جي جي".
2. من القائمة: **Extensions → Apps Script**، امسح الكود الموجود والصق محتوى `apps-script/orders.gs` ثم احفظ.
3. اضغط **Deploy → New deployment**، اختر النوع **Web app**، واضبط:
   - Execute as: **Me**
   - Who has access: **Anyone**
4. اضغط Deploy ووافق على الصلاحيات، ثم انسخ رابط الـ Web app (ينتهي بـ `/exec`).
5. ضع الرابط في `ORDERS_API_URL` داخل `index.html`.

يمكنك التأكد أن السكربت شغال بفتح الرابط في المتصفح: يجب أن تظهر عبارة `Orders endpoint is running`.

عند تعديل `orders.gs` لاحقاً: **Deploy → Manage deployments → Edit → New version**، وإلا يبقى الرابط يشغّل النسخة القديمة.

## ملاحظات
- الصف يُسجَّل في الشيت عند ضغط الزبون "إرسال الطلب"، أما وصول الطلب فعلياً فيتم عند ضغطه "إرسال" داخل واتساب. رقم الطلب موجود في الرسالة وفي الشيت للمطابقة.
- تسجيل الدخول الحالي شكلي (أي بيانات تُقبل).
